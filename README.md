# Minuteur

Un minuteur pour NeoDex. Choisis une durée, lance-le, et NeoDex te prévient quand le temps est
écoulé. Il retient ta dernière durée d'une fois sur l'autre.

## Installer

Dans NeoDex : **NeoStore → À découvrir → Minuteur → Installer**.

## Développer un plugin

Le format et le guide sont dans le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
